# PostureMate 구현 순서

[실시간 자세 코칭 명세](../specs/2026-11-23-posturemate.md)의 인수 조건을 아래 순서로 검증한다. 각 단계에서 먼저 기대 동작이 실패하는지 실행하고, 최소 구현 후 같은 테스트와 회귀 테스트를 실행한다.

1. **CV-1·2·5** — backend/test_pose.py에서 실제 응답 또는 고정 좌표 시퀀스로 가림, 좌우 보정, 짧은 변화, 경고, 복귀와 중단을 검증한다. backend/pose.py에서 세션별 기준과 단조 시계 기반 판정을 구현한다.
2. **CV-3·4** — 같은 좌표를 면접 A/B에 넣고, 발표에서 이동과 왕복의 결과를 비교한다. 손이 무릎보다 높은 구도와 동작 없이 계속 서 있는 구간도 확인한다.
3. **CV-1·6** — backend/app.py, 추론기, backend/coaching.py를 연결한다. 사람이 없는 JPEG의 실제 모델 결과, 누락 모델, 소스를 생략한 요청의 실측 응답, 미지원 소스 거부, 생성 문구 지연을 검사한다.
4. **CV-6·7** — 실제 카메라 요청, 응답 검증, 세 모드의 고정·생성 코칭, 전송 오류 표시와 구도 안내를 React에 연결한다. Node 테스트와 빌드로 검증한다.
5. **CV-8** — 라벨이 있는 영상의 재생·측정 방법과 실행 명령을 제공한다. 로컬 모델 검사, 전체 Python·Node 테스트, 린트, 빌드를 실행하고 실측하지 못한 항목을 명시한다.
