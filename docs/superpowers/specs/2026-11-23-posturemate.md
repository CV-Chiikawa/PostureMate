# PostureMate 실시간 자세 코칭 명세

## 목적과 범위

한 사용자가 노트북에서 거북목·모의면접·발표를 연습하고, 지속되는 자세 변화와 복귀를 확인한다. 기획서 2~6쪽의 제품 요구를 현재 backend 브랜치에 적용한다. 문서의 담당자, 과거 일정, 배포 후보는 실행 지시로 사용하지 않는다. 계정, 영구 이력, 의료 판단은 범위 밖이다.

## 선행 프로젝트와 적용 범위

거북목 모드는 NeckOn AI d57a911의 Finally 엔진을 기준으로 한다. 약 2초간 촬영 구도를 판별해 정면 또는 한쪽 측면을 고정한 뒤 5초간 기준 자세를 수집한다. 보정 도중 자세를 추적할 수 없는 시간은 제외한다. 정면은 깊이와 비대칭의 가중 점수, 측면은 보정된 귀·코 이동량과 CVA 점수 및 BAD 단축 조건을 사용한다. 최근 세 샘플을 평활하고 BAD가 0.5초 지속되면 경고한다. [NeckOn AI 원본](https://github.com/SaltyPie153/NeckOn/tree/d57a911eed2cdb737d446e3aa3702f8d94f83bbd/posture_monitor_ai/Finally)

화면은 최신 프론트의 모드 카드, 색상, 카메라 구도, 결과 타임라인을 사용한다. 실측 결과와 장애 안내를 이 화면에 연결한다. [PostureMate 프론트 기준](https://github.com/CV-Chiikawa/PostureMate/tree/624b1c02c8acae245554b3381a1a6dfec73d7ced)

## 프레임 계약

세 모드 모두 분석 화면에 들어가면 선택한 웹캠의 미리보기를 연다. 분석 시작부터 JPEG를 기존 multipart POST /process-frame 경로로 전송한다. 입력 소스를 생략해도 MediaPipe로 분석하며 다른 소스를 요청하면 422를 반환한다. 권한 거부·장치 해제·서버 장애 시 측정값을 생성하지 않는다. 종료하거나 분석 화면을 떠나면 카메라를 해제한다. JPEG는 메모리에서 해독한다. 코칭에는 유형, 심각도, 지속시간, 측정값, 모드, 루브릭만 전달한다.

## 인수 조건

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| CV-1 | 사람이 없는 프레임, 필수 관절 가림, 화면 밖 좌표 | 측정 불가와 구도 안내. 수치·상태·코칭을 비우고 지속시간을 끊는다. |
| CV-2 | 거북목에서 정면·좌측·우측 구도, 보정, 전방 이동·복귀 | 자동 구도 고정, 개인 기준과 점수 및 BAD 지속 알림 시점을 동일 입력에 대한 NeckOn 결과와 대조한다. |
| CV-3 | 정면 착석 시 손목·무릎이 중앙에 모이거나 각각의 무릎에 놓임 | 같은 화면을 A/B로 구분한다. 손목의 수평·수직 거리 모두 확인한다. 화면상 배치만 판단한다. |
| CV-4 | 발표 중 한 방향 이동, 좌우 왕복, 지속 기울기 | 한 방향 이동은 허용한다. 반복 움직임과 지속 기울기를 별도로 감지한다. 면접에서는 더 작은 흔들림도 평가한다. |
| CV-5 | 기준 초과가 짧거나 연속됨, 정상 복귀, 일시정지·가림 | 면접·발표는 같은 항목의 연속 유효 시간으로 후보 → 2초 주의 → 5초 경고. 정상 복귀 후 같은 알림을 잠시 보류한다. 가림·프레임 공백을 경고 시간으로 더하지 않는다. |
| CV-6 | 세 모드에서 주의·경고 발생, SOLAR 키 없음·지연·오류 | 서버는 고정 문구를 즉시 반환한다. 화면에서 자세 단계나 새 코칭 이벤트가 확정되면 판정과 해당 안내를 함께 갱신한다. 같은 이벤트 안에서 문구가 바뀔 때는 기존 안내를 최소 8초간 보여주고 새 문구가 2초 이상 유지됐는지 확인한다. 측정 불가·일시정지·종료·연결 오류가 표시되면 해당 안내로 전환한다. |
| CV-6a | 자세 변화에 따른 코칭 | 첫 문장은 측정한 변화, 둘째 문장은 바로 할 수 있는 조정 하나를 말한다. 정면에서는 머리 전방 이동과 좌우 기울임을 구별한다. 같은 경고 단계에서 다른 변화가 지속되면 코칭을 갱신한다. SOLAR도 첫 문장을 유지한다. 몸이 보이지 않으면 카메라에 보여야 할 부위만 안내한다. |
| CV-7 | 서버 중단, 재연결, 세션 종료 | 현재 자세와 이전 문구를 구분하고 중복 이벤트 없이 세션 요약을 제공한다. 원본 프레임은 저장하지 않는다. |
| CV-8 | 사람의 정답 구간과 실제 추론을 비교 | 유형별 경고 구간을 일대일 대조한다. 정밀도·재현율, 정상 구간 오경보/분, 분석 FPS와 지연을 보고한다. |

## 검증 기준과 가정

거북목의 정면 기준은 평활값의 평균, 측면 기준은 유효한 사선 구도의 중앙값이다. 측면 CVA는 원본과 같은 정규화 영상 좌표로 계산하며 얼굴 크기의 변화를 보정한다. 세 모드에서 가림·재검출은 1.2초, 같은 측정 상태 내 자세 변경은 0.8초 확인한 뒤 화면을 갱신한다. 장치·서버 오류는 즉시 표시한다. 면접·발표의 정면 상체 좌우 기울기는 어깨 중심과 엉덩이 중심을 잇는 선으로 계산한다. 면접에서는 Pose의 3차원 관절 추정으로 구한 전방 기울기도 함께 보고 두 각도 중 큰 값을 사용한다. 측정이 끊긴 뒤에는 현재 불량 자세가 이전부터 이어졌다고 추정하지 않는다. 수치와 시간 기준은 초기 구현값이며 사람이 라벨링한 영상으로 조정한다.

기획서의 실증 목표는 정밀도와 재현율 각각 80% 이상, 정상 분당 오경보 1회 이하, 외부 서버 5 FPS 이상, 정상망 이벤트 전달 1초 이내다. 실증에는 4명·카메라 환경 2종 이상·시나리오별 2~3회 반복이 필요하다. 합성 좌표의 테스트 통과와 실제 목표 달성은 별도 기록한다.
